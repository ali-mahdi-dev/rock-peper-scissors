## How Does Code Works (principal)
===== Pseudo Code =====
```
X: Player 1
Y: Player 2
```

```
paper = 0;
scissors = 1;
rock = 2;
```

```
<X> vs <Y>
x = y : (0vs0) || (1vs1) || (2vs2)  // tie
scissors vs paper : 1 >  0  // (scissors win)
rock vs scissors  : 2 >  1  // (rock win)
rock vs paper     : 2 >> 0  // (paper win)
```
